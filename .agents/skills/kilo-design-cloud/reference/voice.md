# Kilo Cloud Voice

Kilo Cloud voice is clear, technical, calm, and direct.

## Rules

- Use concrete verbs and specific nouns.
- Use verb + object for actions: `Create workspace`, `Save changes`, `Delete project`.
- Use one term per concept and keep it across a surface.
- Destructive labels name the action and object. Bulk destructive labels include the count when available.
- Errors answer what happened, why if knowable, and what to try next.
- Loading copy names the operation: `Creating workspace...`, not `Loading...`.
- Long waits set expectations with time, phase, or next checkpoint when the product can know it.
- Empty states acknowledge the empty state, explain value, and offer one action.
- Link text stands on its own. Do not use `Click here`.

## Avoid

- `OK`, `Submit`, `Yes`, `No`, and `Click here` as action labels.
- `Oops`, `Whoops`, jokes, or emoji in errors.
- Hype words: powerful, seamless, effortless, revolutionary, magical, unlock.
- User-facing stack traces or `Error:` prefixes.

## Examples

| Weak | Better |
|---|---|
| Submit | Create workspace |
| OK | Save changes |
| Yes | Delete project |
| Delete | Delete 3 workspaces |
| No invoices | No invoices yet. Your first invoice appears after your trial ends. |
| Invalid input | Email must include an @ symbol. Example: you@example.com |
