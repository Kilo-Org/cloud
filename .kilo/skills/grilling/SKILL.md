description: Interview the user relentlessly about a plan or design. Use when the user wants to stress-test a plan before building, or uses any grill trigger phrase.

Interview the user about the plan until you share an understanding. Resolve dependent decisions one at a time. For each question, give your recommended answer.

Ask one question at a time and wait for the answer. If the codebase can answer it, inspect the codebase instead of asking.
