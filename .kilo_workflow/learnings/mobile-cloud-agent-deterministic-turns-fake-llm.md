# mobile: deterministic cloud-agent turns via fake-llm (real-provider turns stall E2E)

Symptom: an E2E verifier starts an app-driven cloud-agent session and the turn never completes: "Considering next steps" for 9+ minutes, or `terminal-failed`, while real-provider routing burns credits and time.

Cause: `KILO_OPENROUTER_BASE` in `services/cloud-agent-next/.dev.vars` points at nextjs (`http://localhost:<nextjs-port>/api`), i.e. real model providers — non-deterministic and slow in dev. Three traps compound it: (1) `e2e/login.sh` signs out first, so re-running login mid-task strands the app on the login screen; (2) a hermetic `platform_integrations` row with a made-up repo passes the composer repo picker but fails dispatch with `GitHub token or active app installation required` — the cached repo must belong to a real, locally mintable installation (e.g. `iscekic/getel`, installation `144771093`); (3) fake-llm stock only knows model `fake-deterministic`, so `models/validate` and the sandbox CLI's catalog lookup reject the app's `kilo-auto/*` selection (`model_missing`, classified `managed_model_configuration`).

Fix (this is the documented exception to the no-LLM-mocking rule; justify each use): set `KILO_OPENROUTER_BASE=http://localhost:<8811+portOffset>/api` in `services/cloud-agent-next/.dev.vars` and `pnpm dev:restart cloud-agent-next`; in `services/cloud-agent-next/test/e2e/fake-llm-server.ts` accept `kilo-auto/*` + `kilo/*` in `handleModelValidation` AND add catalog entries for `kilo-auto/frontier|balanced|efficient` (clone `FAKE_MODEL`, non-zero pricing e.g. `0.000003`/`0.000015`); `pnpm dev:restart fake-llm`. Prompt `__fake__:echo:<text>` in the composer — the assistant replies `<text>` with usage and the session auto-titles. A cloud turn then completes in ~30s. Revert the patch, restore `.dev.vars`, and delete the fixture rows when done.

Limitation: the fake LLM cannot generate tool calls, so it cannot exercise question flows (or any tool-driven behavior) in E2E — those need a real `kilo-auto/efficient` turn.
