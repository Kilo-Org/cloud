# Kilo App Changelog

Newest first: one section per store build, written by the kilo-app Release
workflow after a successful submission. Do not edit this file by hand; the
next build appends its section above the newest one.

## 1.0.15 (build 710 iOS, 711 Android)

### New

- Cloud Agent keeps a lasting history of your sessions that you can return to.
- Cloud Agent chats show the workspace environment they are running in.
- Cloud Agent can reply into a workspace chat or start a new chat for you.
- Cloud Agent environments can now include more than one repository.
- Cloud Agent can watch a pull request and report on it without making changes.
- You can copy your saved custom instructions from the notice that they are being retired.

### Changes

- New paid credits expire one year after purchase.
- Custom instructions are being retired, and the app shows how to take a copy of what you saved.
- Sign-in sessions now have a limited lifetime, so you may be asked to sign in again.

### Fixes

- areas: cloudAgent, securityAgent, notifications

## 1.0.14 (build 551)

- Kilo Pass purchases are no longer available inside the app on iOS and Android.
