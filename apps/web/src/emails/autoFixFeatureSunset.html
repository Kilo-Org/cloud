Auto-Fix Feature Sunset

You're receiving this because you've used the Kilo Auto-Fix feature. We plan to disable the Kilo Auto-Fix feature on {{ disable_date }}.

As a replacement, we've been working on the Kilo for GitHub bot. You can use it to fix issues by installing the GitHub app, then mentioning Kilo in a GitHub issue or pull request comment with the fix you'd like it to make.

Example comments:

@kilocode fix this issue

@kilocode please update this PR to handle the failing test

The main difference from the Kilo Auto-Fix feature is that the bot only responds when mentioned right now, so it will not automatically pick up issues unless you tag it.
